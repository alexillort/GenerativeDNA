// abstract

Bridging natural language and parametric human generation

High-fidelity digital human creation remains a significant bottleneck in interactive media, traditionally requiring extensive manual sculpting and technical rigging expertise. While Generative AI offers text-to-3D capabilities, current methods often produce static meshes lacking the functional topology required for professional animation pipelines.

This work presents Generative DNA, a novel co-creation framework that bridges natural language and parametric generation. By leveraging a fine-tuned Meta Code Llama (Python) model, the system translates semantic prompts into executable Python instructions that directly manipulate the binary genetics of the Epic Games MetaHuman architecture.

Unlike mesh-based approaches, this "Text-to-DNA" pipeline preserves strict topological integrity, ensuring immediate compatibility with Unreal Engine 5 and facial capture systems like Live Link. Non-technical users can generate, visualize, and animate diverse, production-ready phenotypes in seconds — democratizing character creation for game development, virtual production, and HCI research.

A five-layer modular architecture

Generative DNA is a modular, human-in-the-loop system acting as a semantic bridge between natural language and high-fidelity 3D rigging. Five distinct layers each carry a clearly scoped responsibility — from user intent capture to binary .dna file synthesis.

// White-Box Approach

Unlike NeRFs that generate volumetric estimations, the Core Engine performs deterministic surgery on binary .dna files using C++ bindings of the Epic Games DNA Calibration Library — ensuring full editability and immediate pipeline compatibility.

// Genetic Atlas

To prevent geometric "hallucinations," the system uses a structured JSON database indexing 66 validated MetaHuman presets. Semantic queries against phenotypical metadata ensure all interpolations are anatomically plausible — not synthesized from noise.

// dataset

MetaHuman Archetype Repository

The Genetic Atlas consists of 66 calibrated, production-ready MetaHuman phenotypes spanning a wide morphological and ethnic range. Each archetype is stored as a validated .dna binary file and indexed in a structured JSON database — the Genetic Atlas.json — with phenotypical metadata for efficient semantic querying by the Logic Layer.
